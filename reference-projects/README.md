# Reference projects

- `clip-retrieval`: https://github.com/rom1504/clip-retrieval (Apache-2.0), CLIP embedding and FAISS-style retrieval reference.
- `wikimedia-api-demos`: https://github.com/wikimedia/mediawiki-api-demos (GPL-2.0-or-later), Commons API and attribution reference.

These are reference-only; production retrieval is implemented in `backend/app/services/visual_search.py` and `clip_ranker.py`.
